# tinytodo

A tiny, single-file command-line todo list. Stores tasks in `todo.json`
in the current directory.

```
python src/tinytodo.py add "buy milk"
python src/tinytodo.py list
python src/tinytodo.py complete 1
python src/tinytodo.py delete 1
```

This is a small invented project with no connection to CodeCompass,
used only to test-drive an adopted copy of `codecompass-template`.
