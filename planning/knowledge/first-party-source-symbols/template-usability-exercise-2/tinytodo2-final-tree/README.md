# tinytodo2

A tiny, single-file command-line todo list (same design as the earlier
`tinytodo` exercise project). Stores tasks in `todo.json` in the current
directory.

```
python src/tinytodo.py add "buy milk"
python src/tinytodo.py list
python src/tinytodo.py complete 1
python src/tinytodo.py delete 1
```

Invented, non-CodeCompass project used for a complete, commit-permitting
run of the codecompass-template's own heavier-weight clean-room workflow
(Phase 79 sixth amendment, correction 3).
