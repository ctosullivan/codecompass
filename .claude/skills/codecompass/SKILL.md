# codecompass

This project uses codecompass to keep AI-consultable dependency reference docs under `vendor/<name>/`, version-pinned to what's actually installed.

## Commands

- `codecompass sync [vendor]` — regenerate digests and trees.
- `codecompass index` — refresh the root CLAUDE.md routing table.
- `codecompass check [--strict] [--fix]` — staleness gate.
- `codecompass promote <vendor>` — escalate one vendor to `depth = full`: a real AI call, cost-disclosed first.
