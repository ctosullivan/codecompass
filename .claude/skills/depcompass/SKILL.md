# depcompass

This project uses depcompass to keep AI-consultable dependency reference docs under `vendor/<name>/`, version-pinned to what's actually installed.

## Commands

- `depcompass sync [vendor]` — regenerate digests and trees.
- `depcompass index` — refresh the root CLAUDE.md routing table.
- `depcompass check [--strict] [--fix]` — staleness gate.
- `depcompass promote <vendor>` — escalate one vendor to `depth = full`: a real AI call, cost-disclosed first.
